## What I do

I design governed agent systems: models can propose actions, but ordinary software checks permissions, validates outputs, and records receipts before anything consequential happens.

My work is AI-assisted and verification-led. I set the architecture, constraints, controls, and evaluation method; agents help implement; tests and reproducible artifacts decide what survives. I publish negative results when an idea does not beat its controls.

## How I measure claims

- Verify the evaluator before trusting the result.
- Use multiple seeds when variance can change the conclusion.
- Compare against both a no-intervention baseline and a size-matched control.
- Label underpowered results instead of calling them wins or refutations.
- Keep benchmark scope, version, date, and runner attached to the number.

One example: in SCBE experiments, hyperbolic distance did **not** beat cosine similarity on trust AUC. That null result stays visible because a useful system should make its limits as inspectable as its successes.
